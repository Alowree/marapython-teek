This guide will walk you through setting up the modern Fcitx5 input method framework with Wubi (五笔) tables. It is fully optimized for Arch Linux running Hyprland using the modern Lua configuration API layout.

<!-- more -->

## Prerequisites

Ensure your system packages are up to date before starting:

```bash
sudo pacman -Syu
```

Install fonts (optional):

```bash
sudo pacman -S adobe-source-han-sans-cn-fonts adobe-source-han-serif-cn-fonts wqy-microhei wqy-zenhei noto-fonts-cjk noto-fonts-emoji
```

## Step 1: Install Framework & Wubi Tables

Install the Fcitx5 framework, the core Chinese component addons (which include Wubi), and the graphical configuration tool.
Run this command in your terminal:

```bash
sudo pacman -S fcitx5-im fcitx5-chinese-addons fcitx5-configtool
```

- `fcitx5-im`: Installs the core daemon along with GTK and Qt binding modules.
- `fcitx5-chinese-addons`: Provides native engines for Wubi, Pinyin, and Cangjie.
- `fcitx5-configtool`: The graphical interface used to manage your input methods.

## Step 2: Configure Environment Variables (`modules/env.lua`)

For Wayland and GUI applications to recognize and forward text input through Fcitx5, you must set system environment variables. Do not use global system files like `/etc/profile`. Instead, inject them directly via Hyprland's Lua API.
Open your `~/.config/hypr/modules/env.lua` file and add the following block:

```lua
-- Input Method Configurations for Fcitx5
hl.env("GTK_IM_MODULE", "fcitx")
hl.env("QT_IM_MODULE", "fcitx")
hl.env("XMODIFIERS", "@im=fcitx")
hl.env("SDL_IM_MODULE", "fcitx")
hl.env("GLFW_IM_MODULE", "ibus")
```

::: warning ⚠️ Important Syntax Rules:

- Keep values exactly as `"fcitx"`. Appending a `5` (e.g., `fcitx5`) will break input functionality across many flatpaks, web browsers, and Electron applications.
- `GLFW_IM_MODULE` intentionally requires `"ibus"` to remain compatible with Fcitx5 downstream.

:::

## Step 3: Configure Daemon Autostart (`modules/autostart.lua`)

Fcitx5 must run as a background service when your graphical environment launches.
Open your `~/.config/hypr/modules/autostart.lua` file. Wrap the asynchronous execution string inside the `hyprland.start` event listener:

```lua
-- Background Services Initialization
hl.on("hyprland.start", function ()
hl.exec_cmd("fcitx5 -d")
-- Your other autostart modules (like waybar, hyprpaper) go here
end)
```

- `hl.exec_cmd`: Spawns the software completely asynchronously in the background. You do not need to add trailing bash operands like `&`.
- `-d`: Runs Fcitx5 as a background daemon.

## Step 4: Add Wubi to Your Engine Array

To apply your environmental variables and trigger the newly declared background service, log out of your system and log back into your desktop environment.

1. Open your terminal or application runner (like Rofi) and launch the configuration screen:

   `fcitx5-configtool`

2. Uncheck `Only Show Current Language` if it is enabled to expand your visibility search options.
3. Scroll through the left column or type to search for `Wubi` (五笔).
4. Highlight `Wubi` and click the `>` arrow button to add it to your active layout list in the right column.
5. Click `Apply` in the bottom-right corner to save your preferences and exit the wizard.

## Step 5: Test and Switch

1. Open an application (e.g., your browser, terminal, or text editor).
2. Press `Ctrl` + `Space` to trigger the language input method engine.
3. Type your desired structural Wubi configuration layouts. The interactive context dropdown menu should overlay on top of your cursor screen immediately.

If you are using a status bar module like Waybar or AGS, let me know if you would like help implementing a custom module config to track your active Wubi / English layout state visually!

## Special Workspace vs AeroSpace Letter-Named Workspaces

**Not exactly the same!** There's an important distinction:

### AeroSpace letter-named workspaces (B, C, D, etc.)

- **Persistent workspaces** - Always exist, always visible in workspace indicators
- **Normal workspaces** - Just like numbered ones, but with letter names
- **Always accessible** - You can switch to them like any other workspace

### Hyprland Special Workspaces (scratchpads)

- **Hidden by default** - Don't appear in workspace indicators
- **Toggle behavior** - Same key shows/hides
- **Overlay mode** - Appears ON TOP of your current workspace, doesn't switch workspaces
- **Temporary feeling** - Feels like a dropdown/popup

**Better AeroSpace analogy:** Special workspaces are like **AeroSpace's floating windows + toggle** or a **dropdown terminal**, not letter-named workspaces.

## Letter-Named Workspaces in Hyprland (Non-special)

If you want true letter-named workspaces like AeroSpace, you can just use regular workspaces:

```lua
-- Switch to letter-named workspaces (AeroSpace style)
hl.bind(mainMod .. " + G", hl.dsp.focus({ workspace = "name:G" })) -- Git/Code
hl.bind(mainMod .. " + M", hl.dsp.focus({ workspace = "name:M" })) -- Music/Mail
hl.bind(mainMod .. " + W", hl.dsp.focus({ workspace = "name:W" })) -- WeChat/WhatsApp
hl.bind(mainMod .. " + Z", hl.dsp.focus({ workspace = "name:Z" })) -- Zen

-- Move windows to letter-named workspaces
hl.bind(secondMod .. " + G", hl.dsp.window.move({ workspace = "name:G" }))
hl.bind(secondMod .. " + M", hl.dsp.window.move({ workspace = "name:M" }))
hl.bind(secondMod .. " + W", hl.dsp.window.move({ workspace = "name:W" }))
hl.bind(secondMod .. " + Z", hl.dsp.window.move({ workspace = "name:Z" }))
```

## Special Workspaces (Scratchpad) for specific apps

If you prefer the scratchpad behavior for certain apps:

```lua
-- Create special workspaces for different purposes
local special_workspaces = {
    terminal = "special:term",
    calculator = "special:calc",
    music = "special:music",
    messaging = "special:chat"
}

-- Toggle keybinds for special workspaces
hl.bind(mainMod .. " + grave", hl.dsp.workspace.toggle_special("term"))    -- ` key for terminal scratchpad
hl.bind(mainMod .. " + C", hl.dsp.workspace.toggle_special("calc"))         -- Calculator scratchpad
hl.bind(mainMod .. " + M", hl.dsp.workspace.toggle_special("music"))        -- Music scratchpad

-- Send specific apps to special workspaces automatically
hl.on("window", function(win)
    if win.class == "kitty" and win.title:find("scratch") then
        hl.dsp.window.move({ workspace = "special:term" })
    elseif win.class == "Gnome-calculator" then
        hl.dsp.window.move({ workspace = "special:calc" })
    elseif win.class == "Spotify" then
        hl.dsp.window.move({ workspace = "special:music" })
    elseif win.class == "WeChat" or win.class == "Discord" then
        hl.dsp.window.move({ workspace = "special:chat" })
    end
end)
```

## Real-time View of Special Workspaces

**Yes!** Several ways to see your special workspaces:

### 1. **Waybar module** (most common)

Add to your Waybar config (`~/.config/waybar/config`):

```json
"hyprland/workspaces": {
    "format": "{icon}",
    "format-icons": {
        "1": "",
        "2": "",
        "special:magic": "龍",
        "special:term": "",
        "special:calc": "",
        "special:music": ""
    },
    "show-special": true
}
```

### 2. **Eww widget** (more customizable)

```lua
-- In your Eww config
(deflisten special_workspaces "hyprctl workspaces -j | jq '.[] | select(.name | startswith(\"special\")) | .name'")
(defwidget workspaces_special []
  (eventbox :onscroll "scroll" (label :text "${special_workspaces}")))
```

### 3. **CLI command** (manual check)

```bash
# List all workspaces including special ones
hyprctl workspaces -j | jq '.[] | select(.name | contains("special"))'

# Or watch in real-time
watch -n 1 'hyprctl workspaces -j | jq ".[] | select(.name | startswith(\"special\")) | {name, windows}"'
```

### 4. **Custom script for any bar**

Create `~/.config/hypr/scripts/special-workspaces.sh`:

```bash
#!/bin/bash
while true; do
    specials=$(hyprctl workspaces -j | jq -r '.[] | select(.name | startswith("special")) | .name' | tr '\n' ' ')
    echo "Special: [$specials]"
    sleep 1
done
```

### 5. **Hyprland notification** (shows when toggled)

```lua
-- Show notification when toggling special workspace
hl.bind(mainMod .. " + S", function()
    hl.dsp.workspace.toggle_special("magic")
    hl.exec_cmd('notify-send "Scratchpad" "Toggled special workspace"')
end)
```

## Recommendation for you

Since you're coming from AeroSpace with letter workspaces, I'd suggest:

1. **Use regular letter-named workspaces** (not special) for main apps - more similar to AeroSpace
2. **Use special workspaces** ONLY for temporary/dropdown things like:
   - Quick terminal (toggle with `)
   - Calculator
   - Music controls
   - Clipboard history

This hybrid approach gives you the best of both worlds!
